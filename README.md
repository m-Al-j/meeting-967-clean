# Meeting 967 — Operations 967

**الإصدار: v1.11.0**

بوت Discord عربي لإدارة الاجتماعات والفرق والحضور والاعتذارات والتكليفات والتقارير والتسجيلات وسجل التدقيق والنسخ الاحتياطي.

## الوضع الحالي في v1.11.0

هذه النسخة هي خط تشغيل V1 المستعاد والمنظم. الواجهة الأساسية هي `/panel`، وتعمل داخل السيرفر وداخل DM للمستخدم المسموح له. الردود داخل DM عادية وليست `ephemeral`.

الوصول إلى الـDM التشغيلي يُحسم بعضوية المستخدم في سيرفر 967. صلاحية `DM_TRIAL_PERMISSION` ما زالت موجودة كخدمة داخلية للتوافق مع الأجزاء التي تستخدمها، لكنها ليست بوابة لوحة DM الإنتاجية.

## التسجيل والتسليم

لا يُنشر التسجيل النهائي إلا بعد اجتياز حماية سلامة التسجيل:

- الحالة `completed`
- ملف نهائي واحد فقط في `final_paths`
- `integrityGuardVersion=1.10.11`
- `integrityStatus=verified`

التسليم النهائي للتسجيل يتم داخل قناة الفريق فقط. الملفات حتى 7MB تُرسل كمرفق Discord، والأكبر تُرفع إلى Catbox كرابط واحد. لا يوجد مسار نشط لإرسال التسجيل النهائي إلى DM ولا مسار Google Drive في خدمة التسليم الحالية.

## الأوامر الأساسية

- `/panel` — لوحة العمليات والأدوات بحسب صلاحيات الحساب.
- `/setup` — الإعداد الإداري.
- `/health` — الفحص التشغيلي.

باقي التشغيل يتم من خلال الأزرار والقوائم والنوافذ المنبثقة مع إعادة فحص الصلاحيات عند التنفيذ.

## المتطلبات

- Node.js **22.12+**
- PostgreSQL **14+**
- Discord Application/Bot
- صلاحية Server Members Intent من Discord Developer Portal

## الإعداد

انسخ ملف البيئة:

```bash
cp .env.example .env
```

ثم أدخل القيم الخاصة بجهازك فقط:

```env
DISCORD_TOKEN=
CLIENT_ID=
GUILD_ID=
OWNER_USER_ID=
DATABASE_URL=
```

لا تضع أسرارًا داخل ملفات `.env.*` الاحتياطية أو المستودع. ملفات البيئة الاحتياطية غير مطلوبة للتشغيل.

## التحقق قبل التشغيل

```bash
npm ci
npm run migrate
npm run lint
npm test
npm run doctor
```

لا تستخدم `npm run seed` على قاعدة بيانات تشغيلية تحتوي بيانات حقيقية إلا بعد مراجعة ما سيضيفه الـseed.

بعد نجاح التحقق ونشر أوامر Discord:

```bash
npm run deploy
npm start
```

## التشغيل المُدار على Termux

```bash
npm run managed:start
npm run managed:status
npm run managed:logs
npm run managed:restart
npm run managed:stop
```

## ملفات التشغيل

`src/` للكود الفعلي، `migrations/` لتغييرات قاعدة البيانات، `tests/` لاختبارات السلوك، `ops/` للتشغيل والإشراف، و`docs/` للتوثيق التفصيلي.

ملفات النسخ القديمة والملفات المؤقتة وأسرار البيئة ليست جزءًا من حزمة النشر النظيفة.
